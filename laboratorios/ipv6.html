IPv6 y rutas estáticas

ipv6 unicast-routing, direcciones, link-local y rutas IPv6

Nivel: Intermedio Tiempo: 30 min Dominio 3.0 Conectividad IP

Escenario

La red migra a IPv6. R2 ya está configurado, salvo su ruta hacia la LAN de PC1. R1 está sin nada de IPv6.

En R1, activa el enrutamiento IPv6, pon 2001:DB8:1::1/64 en G0/0 con la link-local FE80::1 (es la puerta de enlace de PC1) y 2001:DB8:12::1/64 en G0/1. Crea una ruta por defecto IPv6 por 2001:DB8:12::2. En R2, añade la ruta a 2001:DB8:1::/64 por 2001:DB8:12::1.

Comprueba con ping 2001:DB8:2::10 desde PC1.

Configuración de partida

En la app esto viene hecho. En Packet Tracer, antes de empezar, entra en cada equipo con enable y configure terminal y escribe (o pega) estas líneas.

R1hostname R1 no ip domain-lookup interface g0/0 no shutdown interface g0/1 no shutdown
R2hostname R2 no ip domain-lookup ipv6 unicast-routing interface g0/0 ipv6 address 2001:db8:12::2/64 no shutdown interface g0/1 ipv6 address 2001:db8:2::1/64 ipv6 address fe80::2 link-local no shutdown

PC y servidores (Desktop › IP Configuration)

  • PC1: IPv6 2001:DB8:1::10/64, puerta de enlace FE80::1
  • PC2: IPv6 2001:DB8:2::10/64, puerta de enlace FE80::2

Tareas

Lo que tiene que quedar funcionando. En la app, cada una se marca sola en cuanto la consigues.

  1. R1 enruta IPv6
  2. G0/0: 2001:DB8:1::1/64 y link-local FE80::1
  3. G0/1: 2001:DB8:12::1/64
  4. R1: ruta por defecto ::/0 por 2001:DB8:12::2
  5. R2: ruta a 2001:DB8:1::/64 por 2001:DB8:12::1
  6. PC1 llega a PC2 por IPv6
  7. Comprobado con show ipv6 route
En Packet Tracer
  • La dirección IPv6 de cada PC se pone en Desktop › IP Configuration, en el apartado IPv6 (Static).
  • En la configuración de partida, R1 solo enciende sus interfaces; R2 trae ya su IPv6.
Pistas
  • R1 enruta IPv6: ipv6 unicast-routing (sin esto el router no reenvía IPv6)
  • G0/0: 2001:DB8:1::1/64 y link-local FE80::1: ipv6 address 2001:db8:1::1/64 y ipv6 address fe80::1 link-local
  • G0/1: 2001:DB8:12::1/64: interface g0/1 → ipv6 address 2001:db8:12::1/64
  • R1: ruta por defecto ::/0 por 2001:DB8:12::2: ipv6 route ::/0 2001:db8:12::2
  • R2: ruta a 2001:DB8:1::/64 por 2001:DB8:12::1: ipv6 route 2001:db8:1::/64 2001:db8:12::1
  • PC1 llega a PC2 por IPv6: Desde PC1: ping 2001:db8:2::10
  • Comprobado con show ipv6 route: show ipv6 route en R1

Solución paso a paso

Inténtalo antes por tu cuenta: se aprende mucho más escribiendo los comandos tú.

Ver la solución

1Activa el enrutamiento IPv6 R1

Sin ipv6 unicast-routing el router tiene direcciones IPv6 pero no reenvía paquetes.

R1enable configure terminal ipv6 unicast-routing

2Direcciones de G0/0 R1

La link-local FE80::1 es la que PC1 usa como puerta de enlace: fijarla a mano la hace fácil de recordar.

R1interface g0/0 ipv6 address 2001:db8:1::1/64 ipv6 address fe80::1 link-local

3Dirección de G0/1 R1

R1interface g0/1 ipv6 address 2001:db8:12::1/64 exit

4Ruta por defecto IPv6 R1

::/0 es el equivalente IPv6 de 0.0.0.0/0.

R1ipv6 route ::/0 2001:db8:12::2 end

5Ruta de vuelta en R2 R2

R2enable configure terminal ipv6 route 2001:db8:1::/64 2001:db8:12::1 end

Errores típicos

  • Olvidar ipv6 unicast-routing: todo parece bien, pero el router no reenvía.
  • Usar una link-local como siguiente salto sin indicar la interfaz de salida.
