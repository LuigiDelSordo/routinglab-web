Interfaces y direccionamiento

Direcciones IP, descripciones, no shutdown y loopback

Nivel: Básico Tiempo: 20 min Dominio 1.0 Fundamentos de red

Escenario

R1 une dos redes: la de PC1 (192.168.1.0/24) por G0/0 y la de PC2 (192.168.2.0/24) por G0/1. Los PC ya tienen su IP y su puerta de enlace, pero el router está sin configurar y sus interfaces vienen apagadas de fábrica.

Asigna las direcciones de la tabla, pon una descripción a cada interfaz, enciéndelas y crea la Loopback0 con 10.0.0.1/32. Al final, comprueba que los PC se ven entre sí (desde la consola de PC1: ping 192.168.2.10) y revisa el estado con show ip interface brief.

Configuración de partida

En la app esto viene hecho. En Packet Tracer, antes de empezar, entra en cada equipo con enable y configure terminal y escribe (o pega) estas líneas.

R1hostname R1 no ip domain-lookup

PC y servidores (Desktop › IP Configuration)

  • PC1: IP 192.168.1.10, máscara 255.255.255.0, puerta de enlace 192.168.1.1
  • PC2: IP 192.168.2.10, máscara 255.255.255.0, puerta de enlace 192.168.2.1

Tareas

Lo que tiene que quedar funcionando. En la app, cada una se marca sola en cuanto la consigues.

  1. G0/0 con 192.168.1.1/24 y una descripción
  2. G0/1 con 192.168.2.1/24 y una descripción
  3. Las dos interfaces encendidas (up/up)
  4. Loopback0 con 10.0.0.1/32
  5. PC1 llega a PC2
  6. PC1 llega a la Loopback0
  7. Comprobado con show ip interface brief
En Packet Tracer
  • Conecta cada PC directamente al router con un cable cruzado (o con el de conexión automática, el rayo). Las luces del cable se quedarán en rojo hasta que hagas no shutdown.
  • La IP de cada PC se pone en Desktop › IP Configuration.
Pistas
  • G0/0 con 192.168.1.1/24 y una descripción: interface g0/0 → description LAN-PC1 → ip address 192.168.1.1 255.255.255.0
  • G0/1 con 192.168.2.1/24 y una descripción: interface g0/1 → description … → ip address 192.168.2.1 255.255.255.0
  • Las dos interfaces encendidas (up/up): Las interfaces de un router vienen con shutdown: entra en cada una y escribe no shutdown
  • Loopback0 con 10.0.0.1/32: interface loopback 0 → ip address 10.0.0.1 255.255.255.255 (se crea al entrar)
  • PC1 llega a PC2: Si falla, revisa la IP y el estado de las dos interfaces con show ip interface brief
  • PC1 llega a la Loopback0: Desde PC1: ping 10.0.0.1
  • Comprobado con show ip interface brief: En modo privilegiado (o con do desde configuración): show ip interface brief

Solución paso a paso

Inténtalo antes por tu cuenta: se aprende mucho más escribiendo los comandos tú.

Ver la solución

1Configura G0/0, la LAN de PC1 R1

Las interfaces de un router vienen apagadas de fábrica (administratively down): sin no shutdown no pasa nada aunque la IP esté bien.

R1enable configure terminal interface g0/0 description LAN-PC1 ip address 192.168.1.1 255.255.255.0 no shutdown

2Configura G0/1, la LAN de PC2 R1

Al escribir interface g0/1 dentro de otra interfaz, IOS cambia directamente a la nueva: no hace falta salir antes.

R1interface g0/1 description LAN-PC2 ip address 192.168.2.1 255.255.255.0 no shutdown

3Crea la Loopback0 R1

Una loopback es una interfaz lógica que siempre está arriba. Se crea al entrar en ella y suele llevar una /32.

R1interface loopback 0 ip address 10.0.0.1 255.255.255.255 end

Verificación

Las tres interfaces configuradas deben salir con Status y Protocol en up. «administratively down» significa que falta no shutdown; «down/down», que no hay cable o el otro extremo está apagado.

R1R1#show ip interface brief Interface IP-Address OK? Method Status Protocol GigabitEthernet0/0 192.168.1.1 YES manual up up GigabitEthernet0/1 192.168.2.1 YES manual up up GigabitEthernet0/2 unassigned YES unset administratively down down Loopback0 10.0.0.1 YES manual up up

El primer eco puede perderse mientras el router resuelve la MAC por ARP; los siguientes responden con TTL=127 (128 menos el salto del router).

PC1C:\>ping 192.168.2.10 Pinging 192.168.2.10 with 32 bytes of data: Reply from 192.168.2.10: bytes=32 time<1ms TTL=127 Reply from 192.168.2.10: bytes=32 time<1ms TTL=127 Reply from 192.168.2.10: bytes=32 time<1ms TTL=127 Reply from 192.168.2.10: bytes=32 time<1ms TTL=127 Ping statistics for 192.168.2.10: Packets: Sent = 4, Received = 4, Lost = 0 (0% loss), Approximate round trip times in milli-seconds: Minimum = 0ms, Maximum = 0ms, Average = 0ms

Errores típicos

  • Escribir la IP con la máscara en formato /24: IOS solo acepta la máscara completa (255.255.255.0).
  • Poner la misma red en dos interfaces: IOS lo rechaza con «% … overlaps with …».
